# Prior art and reuse

This method combines existing editorial, qualitative and knowledge-work practices. The supporting consultation was bounded, not an exhaustive systematic review or proof of a novel combination.

| Precedent | Adopted mechanism and limit |
|---|---|
| [Huitfeldt on the Bergen Wittgenstein edition](https://tei-c.org/Vault/ETE/Preview/huitfeldt.html) | Closest editorial analogue: repeated formulations, unresolved alternatives, documentary fidelity and linked reading views. A normalized transcription is not a newly synthesized philosophy; borrow the distinction, not manuscript machinery. |
| [TEI critical apparatus](https://guidelines.tei-c.de/en/html/TC.html) and [primary sources](https://guidelines.tei-c.de/en/html/PH.html) | Separate variants, attribution, editorial responsibility and certainty; no compulsory XML ontology. |
| [Gale et al., Framework Method](https://doi.org/10.1186/1471-2288-13-117) | Context-preserving comparisons, anomalous cases and revisable categories. Apply locally to comparable material, rather than forcing heterogeneous corpora into one grid. |
| [Grossoehme and Lipstein, longitudinal analysis](https://doi.org/10.1186/s13104-016-1954-1) | Follow issue trajectories over time. Its application to one author's intellectual development is an adaptation. |
| [PRISMA-S](https://www.prisma-statement.org/prisma-search) and [Cochrane living reviews](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-22) | Transparent discovery, screening and updates. Reporting discipline does not prove discovery recall or exhaustive interpretation. |
| [Hennink et al., code versus meaning saturation](https://doi.org/10.1177/1049732316665344) | New meanings can remain after topic labels stop appearing. No universal numerical stopping rule is imported. |
| [Compendium](https://research-archive.stem.open.ac.uk/compendium/) | Questions, positions, reasons and objections as useful argument structure; no dedicated mapping application required. |
| [Matuschak, evergreen notes](https://notes.andymatuschak.org/Evergreen_notes) | Linked revisable accounts with useful conceptual boundaries. Neither atomic-note maximalism nor one giant document is mandatory. |
| [Birt et al., member checking](https://doi.org/10.1177/1049732316654870) | An owner can engage with and add to an interpretation. Current clarification does not retroactively establish prior assent. |
| [CHOIR](https://choir.cs.vt.edu/) | Conversation-grounded document revision is a close operational neighbor; it is not itself exhaustive retrospective harvesting. |
| [PROV-O](https://www.w3.org/TR/prov-o/) | Distinguish attribution, derivation and revision. Provenance establishes neither truth nor endorsement. |

Memory systems such as [A-MEM](https://arxiv.org/abs/2502.12110) and evaluations such as [LongMemEval](https://arxiv.org/abs/2410.10813) address enabling memory/retrieval capabilities; they do not substitute for interpretive authority or source-grounded editorial judgment.

Create a distinct skill and compose existing capabilities. Retrieval belongs to recall or native archives; difficult decomposition belongs to modularize; consequential clarification can use elicit. Metabolize-sources aims to incorporate or enact durable value so source material can be retired. A living intellectual corpus keeps historical sources available for reinterpretation and citation, so retirement cannot govern this workflow.

The method's practical synthesis is readable current prose over inspectable source versions, issue-level evolution, proportional evidence, and honest coverage boundaries. Its span register and checkpoint rules are design choices for this workflow, not claims of universal disciplinary consensus.
