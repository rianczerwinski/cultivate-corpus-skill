# cultivate-corpus

Build a revisable, source-grounded corpus of a person’s thinking while preserving attribution, unresolved alternatives, and evolution.

## Use

> Integrate these conversations into my existing corpus, keeping the original claims and their sources distinguishable.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `cultivate-corpus/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
